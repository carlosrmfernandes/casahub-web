# casahub-web — Casa em Dia

Front-end (React + Vite) do app Casa em Dia. Feito para usar no celular; no computador vira um menu lateral.

## Rodar local

```
npm install
cp .env.example .env   # VITE_API_URL aponta para a API (padrão http://localhost:3333)
npm run dev
```

Abra http://localhost:5173, crie sua conta e vá em **Contas → Contas fixas**: a lista de contas da casa já vem preenchida para conferir e salvar.
